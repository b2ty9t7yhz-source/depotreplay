# Security policy

DepotReplay is a local strategy game and does not process network traffic. Treat scenario, save, and replay files as untrusted input: validation and hash verification reject malformed or altered content, but hashes do not provide authorship or authenticity.

Please report a suspected vulnerability privately to the repository owner rather than opening a public issue. Include the affected revision, a minimal artifact, and reproduction steps. Do not include secrets or personal data.
